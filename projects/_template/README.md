# Project Template

Use this folder as the starter for new experiments.

## Steps

1. Copy `projects/_template` to `projects/<project-slug>`.
2. Update `index.html` with your project.
3. Replace this README with a project-specific description.
4. Add your project entry to the root `index.html` gallery.
5. Add your project entry to the root `README.md` table.

## Naming Convention

- Use lowercase kebab-case for folder names.
- Examples: `ripple-trails`, `audio-portal`, `hands-orbit`.
